# Data

`amazonhelp_cleaned_with_intents.csv` is the cleaned AmazonHelp
customer-response dataset used by the project.

Columns:

- `cleaned_customer_message`
- `cleaned_amazon_response`
- `Intent`

The dataset contains manually labelled examples used for intent
classification and a larger historical corpus used for retrieval.

The original source is the Customer Support on Twitter dataset:

- `https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter`

The original dataset should be obtained from its official/source distribution.
